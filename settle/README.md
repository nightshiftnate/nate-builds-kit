# Find settlements you might qualify for

From the "Ask ChatGPT which lawsuits might owe you money" carousel.

AI can help you find class action settlements and refunds to look into. It can't tell you for sure that you qualify, and it can be wrong. Treat what it finds as a list to check, and only ever file on the official site.

## 1. Start with the FTC

The FTC runs refund programs from its own cases. Its FAQ says: "Most FTC cases do not require you to file a claim." If you're owed money, the FTC usually sends it.

One example: for the FTC's Amazon refunds, the FTC says "If you are eligible, no action is needed."

## 2. Ask ChatGPT to search

Paste this and fill in the brackets:

```
Search the web for open class action settlements I might qualify for. I've used: [apps, stores, banks]. Give me each official claim site and deadline.
```

ChatGPT search is on every plan, Free included.

## 3. Ask Claude to search your inbox

If you've connected Gmail to Claude, it can search your email in plain English. Try:

```
Search my email for class action settlement notices, claim forms or refund notices from the last two years.
```

Claude asks before it sends, replies to or forwards anything, unless you've turned on Auto mode.

## 4. Two real ones, open as of 26 November 2026

- **GoodRx privacy settlement.** Claim forms must be submitted online or postmarked by **December 29, 2026**. Official site: [goodrxprivacysettlement.com](https://www.goodrxprivacysettlement.com)
- **American Express telephone settlement ($12 million).** For people who got prerecorded or artificial voice calls from or for American Express about a credit card account that wasn't theirs. Respond by **January 21, 2027**. Official site: [amextelephonesettlement.com](https://amextelephonesettlement.com/)

Read each site's own rules on who qualifies before you file.

## 5. Check everything yourself

Claude's help center says users "should not rely on Claude as a singular source of truth." The same goes for ChatGPT. For every result:

- Open the official settlement site yourself. Don't trust a link from a random post.
- Read who qualifies and the deadline on that site.
- File only on that site.

## 6. Never pay to get a refund

From the FTC: "Never pay money or give sensitive financial information to get a refund payment from the FTC." If someone asks for a fee to get you a refund, walk away.
